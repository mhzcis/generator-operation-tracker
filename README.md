# نظام متابعة تشغيل المولدات

تطبيق عربي RTL يعمل محليًا بالكامل (Local-First PWA) لإدارة المولدات وسجلات التشغيل اليومية، مع رسوم بيانية وتقارير ونسخ احتياطي تلقائي. لا يرسل أي بيانات إلى خادم.

## التشغيل المحلي

```bash
npm install
npm run test
npm run dev
```

## فحص وبناء نسخة الإنتاج

```bash
npm run test
npm run build
npm run preview
```

## النشر على GitHub Pages

1. أنشئ مستودع GitHub جديدًا وارفع **محتويات هذا المجلد** إلى فرع `main`.
2. من `Settings > Pages` اختر المصدر `GitHub Actions`.
3. سيعمل المسار `.github/workflows/deploy.yml` تلقائيًا، وينفذ الاختبارات والبناء ثم النشر.

## قواعد التشغيل المهمة

- مولد واحد يحمل رقمًا فريدًا، ولا يحذف فعليًا بل يعطّل.
- يدعم تعريف المولد حقولًا اختيارية للقدرة وإحداثيات الموقع الجغرافي: **إحداثيات العرض (`latitude` بين -90 و 90)** و**إحداثيات الطول (`longitude` بين -180 و 180)**.
- سجل واحد لكل مولد يوميًا، والأحدث فقط قابل للتعديل أو الحذف.
- يمنع إدخال سجل بتاريخ سابق على مستوى كل مولد: أول سجل يقبل تاريخ اليوم أو أي تاريخ سابق، وكل سجل لاحق يبدأ تاريخه الافتراضي والأدنى من تاريخ أحدث سجل للمولد + يوم واحد، ولا يسمح بتاريخ مستقبلي. إذا كان أحدث سجل بتاريخ اليوم يُعطَّل الحفظ حتى اليوم التالي. التحقق نفسه مطبق في طبقة الخدمة.
- يمكن تعيين مولد نشط واحد فقط افتراضيًا من بطاقته في صفحة المولدات، ويُختار تلقائيًا عند فتح سجل جديد. تعطيل المولد يلغي افتراضيته.
- أول قراءة سابقة تُدخل يدويًا، ثم تُجلب آليًا.
- السجل اليومي يحسب الفرق بين القراءتين بدقة عشرية مضبوطة (`roundHours`).
- تغيير العداد يسمح بقراءة أقل ويضيف صفر ساعة لهذا الحدث، ثم تصبح قراءته الحالية أساس السجل اللاحق، دون فقد الساعات التاريخية.
- بعد كل إضافة أو تعديل للمولد، وكل إضافة أو تعديل أو حذف للسجل، ينزل المتصفح نسخة JSON تلقائيًا (مع دعم الربط عبر `File System Access API` في المتصفحات الداعمة).
- التطبيق يدعم التثبيت كتطبيق ويب تقدمي (`PWA`) للعمل دون اتصال بالإنترنت (`Offline-Ready`).

## الاستعادة

من صفحة سجل التشغيل اختر **استعادة** وحدد ملف JSON. قبل الاستبدال ينزل التطبيق نسخة أمان من البيانات الحالية تلقائيًا.

قبل الاستبدال يتحقق التطبيق من حجم الملف والإصدار والبنية، وتكرار أرقام المولدات، وصحة أسماء المولدات ومواقعها وإحداثياتها، والسجلات اليتيمة أو المكررة في اليوم نفسه، والتواريخ والقراءات وأنواع السجلات والملاحظات، والتسلسل الزمني لكل مولد. عند فشل أي تحقق تُلغى الاستعادة بالكامل مع رسالة بالسبب ولا تتغير البيانات الحالية. يُعاد حساب اليوم من التاريخ وساعات التشغيل من القراءات (تغيير العداد = صفر).

### التوافق والترحيل

صيغة النسخة بقيت `1.0` دون تغيير أسماء الحقول الأساسية. الحقول `isDefault` و`latitude` و`longitude` في المولد اختيارية: عند غيابها في البيانات القديمة أو في `localStorage` تعامل القيمة الافتراضية (`false` لـ `isDefault` ونص فارغ للإحداثيات). لذلك لا يلزم ترحيل لإصدار جديد.

## الخصوصية

كل البيانات محفوظة في `localStorage` للمتصفح. حذف بيانات المتصفح يحذف النسخة المحلية، لذلك احتفظ بملفات النسخ الاحتياطي في مكان آمن.
